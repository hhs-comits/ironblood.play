# Play IRONBLOOD in your browser

**Play:** https://hhs-comits.github.io/ironblood.play/

IRONBLOOD is a barbarian-age real-time strategy game. This repository holds only the
built browser version (Godot 4.4 web export); the source code is kept elsewhere.

- Chrome, Edge or Firefox on a PC with a graphics card.
- On first start press **Download the game data** (about 29 MB, kept by your browser),
  or **Use my installed game** and choose `Ironblood.exe` from the Windows version.
- **Network game:** the host presses *Host Network Game* and gets a short join code
  (plus an invite link and QR code); up to three friends type the code under *Join* or
  open the link. Players connect directly, no port forwarding. Browser players and Windows
  players can play each other, as long as both have the same version.
- **Windows version:** [download ironblood-windows-v0.70.zip](https://github.com/hhs-comits/ironblood.play/releases/download/v0.70/ironblood-windows-v0.70.zip)
  (all versions and notes: [Releases](https://github.com/hhs-comits/ironblood.play/releases/latest))
  The start page of the browser version has the same download: **Download the PC game (Windows zip)**.
  (unzip and keep `Ironblood.exe` next to the `.dll`; the dll is needed for online games).
  The browser version is now v0.90 (v0.90: selected watchtowers, castles and other buildings that shoot show their range as a light green circle, a Stronghold two (arrows and war engine); v0.89: a Credits screen in the main menu with the art and sound credits and the software licenses, and new whoosh sounds for swings, arrows and throwing arms; v0.88: buildings show their level, the Upgrade button shows the step it buys and is gone at the last level, and Builders matches vary all numbers a little each game and keep everything inside your borders in view; v0.87: the Builders top bar fits the screen, leaving full screen no longer crashes the game, and selected archers and other ranged units show a light green range circle; since v0.75: the four peoples, four new land types, the Builders
  version, every building, wall, siege engine, mine, animal and horse, the clothes, weapons, shields and
  helmets of every unit, the trees, woods, grass and rocks, the arrows and missiles, and the smoke, dust,
  sparks, splashes and lightning modelled in Blender, new command
  icons and wood-and-bronze buttons, and recovery when a network game goes out of sync). The Windows zip
  follows once the release workflow runs again (after 2026-11-21).
  Until then the Windows v0.70 and the browser v0.90 cannot join each other's network games.

To play offline on Windows, download this repository as a zip and double-click
`Play IRONBLOOD in browser.bat` (see `HOW_TO_PLAY_BROWSER.txt`).
