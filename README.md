# Play IRONBLOOD in your browser

**Play:** https://hsan24816-commits.github.io/ironblood.play/

IRONBLOOD is a barbarian-age real-time strategy game. This repository holds only the
built browser version (Godot 4.4 web export); the source code is kept elsewhere.

- Chrome, Edge or Firefox on a PC with a graphics card.
- On first start press **Download the game data** (about 16 MB, kept by your browser),
  or **Use my installed game** and choose `Ironblood.exe` from the Windows version.
- **Phones and tablets:** open the same link with the phone turned sideways. Touch controls
  and lighter phone graphics switch on by themselves (tap to select or order, hold then drag
  for a box, drag to move the map, pinch to zoom, buttons on the right). Phones and PCs can
  play the same network game.
- **Network game:** the host presses *Host Network Game* and sends the invite code; the
  friend pastes it under *Join* and sends back the reply code; the host pastes that and
  presses *Connect*. Players connect directly, no server or port forwarding.

To play offline on Windows, download this repository as a zip and double-click
`Play IRONBLOOD in browser.bat` (see `HOW_TO_PLAY_BROWSER.txt`).
